# WhatCityAreYou
A travel-themed quiz - Creative Coding A2 project - 
Players answer 10 questions about their interests and everyday preferences, then receive a city match: Paris, Tokyo, Barcelona, New York or Sydney. The idea is to offer a fun way to imagine a different lifestyle or a future trip.

# How to play
Click **Find my city** and choose one answer per question. Each answer adds one point to a city, and the highest-scoring city becomes the result. If there is a tie, a final mood question lets the player choose between the tied cities.
- The **Back one question** button lets players change an answer without counting the previous choice twice.

The result includes a city photo, a description and suggested activities. Players can then restart or return to the welcome screen.

# Files
- `WhatCityAreYou.FINAL.py' — the quiz program.
- `images/` — the five city photos.
- `requirements.txt` — lists Pillow, the extra library needed for the photos.
- `README.md` — these instructions.

Keep the `images` folder beside the Python file. 

# Setup
The game needs Python 3 with IDLE and Tkinter, plus Pillow for the photos. Pillow must be installed.
If the photos do not appear, check that Pillow is installed and the `images` folder is beside the Python file. Filenames must match exactly, including `.jpg` and the underscore in `new_york.jpg`.
